# Roadmap

These are proposed milestones, not completed features or release dates.

1. **Foundation:** rename and validate the official native template, preserve its
   attribution, set up CI, and document compatibility and Windows/WSL development.
2. **Capability proof:** build/play on the recorded Horizon pin, choose supported
   authoritative events, and show one item's memory in a tooltip. Prove save/reload,
   dropping/pickup, chest storage and transfer preserve that item's own memory.
3. **Ember Path:** one sword, varied fire/Blaze discoveries, one essence, and an
   explicit Flame Burst versus Cinder Guard binding with a cooldown.
4. **Readable interaction:** a small attunement UI and optional journal hints.
   A spatial/3D GUI is outside the initial scope.
5. **Public alpha:** a clean-world playtest, installation instructions, demo,
   compatibility evidence, licence/reviewer permission resolution and registry submission.

Later ideas: Creeper arrows, Spider night vision, rabbit boots, mining affinities,
and a bat/potion ritual. They should reuse a proven loop rather than all ship in v0.1.

Success means a player understands a surprising discovery and wants to experiment
again. Repetitive kill-count farming is not the primary progression gate.
