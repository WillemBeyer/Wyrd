# Contributing

Read README.md, docs/DEVELOPMENT.md and AGENTS.md first. Keep contributions small
and explain the observed behavior, intended change and validation performed.
Gameplay ideas belong in issues or design notes before broad implementation.

Run formatting, clippy, unit tests, the compiled fixture and packaging. Bundle or
compatibility changes also need full pinned-source stage/check/test evidence.
Never present unrun checks as passing. Avoid committing generated builds, game
assets, player worlds or secrets. Preserve all upstream copyright notices.

Contributions to Wyrd are made under the existing GPLv3 project licence; the
inherited MIT portions keep their notices. There is no automatic release or
registry publication from a push.
